# Alternatif speech-to-speech untuk NAIL

23 November 2026. Perbandingan ini mengasumsikan audio masuk dan jawaban berbahasa Indonesia di Meet atau Teams. Harga dalam USD. Latensi, kualitas suara, dan biaya per rapat belum diuji langsung.

## API suara real-time

**Mulai dengan Qwen3.8 Omni Flash Realtime di Singapura untuk biaya berbayar terendah di antara kandidat yang diperiksa.** Model mendukung audio dua arah, WebRTC dan WebSocket, serta keluaran bahasa Indonesia dengan suara `Tina` atau `Rizky`. **Gunakan Gemini 3.8 Live sebagai pembanding** karena Google mendokumentasikan dukungan bahasa Indonesia dan paket gratis per proyek. ## Opsi lokal tanpa tagihan API

**Untuk Mac M1 8 GB, mulai dengan pipeline lokal bertahap.** Pakai Whisper `base` multibahasa untuk transkrip Indonesia, dengan pembanding `whisper.cpp` di Metal atau Core ML. Jalankan model teks kecil terkuantisasi seperti Gemma 4 E2B IT via `llama.cpp`, lalu ucapkan frasa awal saat token LLM masih keluar. `say` dengan Damayanti sudah tersedia di NAIL sebagai pembanding lokal bawaan macOS. Jika ingin bobot yang dapat diunduh, Laras memakai Pocket TTS Indonesian dengan bobot CC BY 4.0 dan kode MIT/Apache 2.0. Supertonic 3 juga mendukung `id` melalui ONNX di CPU dengan bobot OpenRAIL-M. Ukur tekanan memori saat Electron, ASR, dan model teks berjalan bersamaan. [Whisper Indonesia](https://github.com/openai/whisper/blob/main/whisper/tokenizer.py) · [whisper.cpp](https://github.com/ggml-org/whisper.cpp) · [Gemma](https://huggingface.co/google/gemma-4-E2B-it) · [Laras](https://github.com/Urdemonlord/laras-tts) · [Pocket TTS Indonesian](https://huggingface.co/anak10thn/pocket-tts-indonesian) · [Supertonic 3](https://huggingface.co/Supertone/supertonic-3) · [Damayanti di NAIL](../../NAIL/Resources/agy-voice.py#L720)

Hugging Face `speech-to-speech` menyediakan server pipeline Apache 2.0 dengan WebRTC dan WebSocket serta event inti OpenAI Realtime. Untuk prototipe bahasa Indonesia, pilih Whisper MLX multibahasa dengan `--language id`, LLM kecil, serta backend Supertonic. Setiap komponen bisa diganti agar sesuai dengan batas memori Mac. [Pipeline dan dukungan bahasa](https://github.com/huggingface/speech-to-speech#multi-language-support) · [Protokol Realtime](https://github.com/huggingface/speech-to-speech#realtime-api)

## Dampak pada jalur suara NAIL

- **Codex Live Voice** adalah pembanding yang sudah ada. Mode manual membuat jembatan WebRTC melalui `thread/realtime/start` dengan `gpt-live-1-codex`. Mode *hands-free* merekam giliran, mendeteksi panggilan dengan Whisper, lalu meneruskan teks. **Antigravity** menjalankan Whisper → LLM → TTS dan membaca WAV lengkap sebelum pemutaran di rapat. Opsi ElevenLabs di jalur ini membaca seluruh MP3 sebelum mengonversinya ke WAV. [Sesi Codex](../../NAIL/Resources/codex-voice.cjs#L493) · [Pemicu hands-free](../../NAIL/Resources/meet.cjs#L1711) · [Sintesis Antigravity](../../NAIL/Resources/agy-voice.py#L994) · [Pembacaan WAV](../../NAIL/Resources/meet.cjs#L1907) · [MP3 ElevenLabs](../../NAIL/Resources/agy-voice.py#L795) · [Konversi ke WAV](../../NAIL/Resources/agy-voice.py#L817)
- Untuk uji native, gunakan jembatan audio Meet yang sudah ada sebagai titik integrasi. Pertahankan mode siaga dan notulen lokal, lalu kirim audio ke API saat mode jawab aktif. Qwen menerima WebRTC. Gemini Live memakai WebSocket dengan PCM 16 kHz masuk dan 24 kHz keluar, sehingga jalurnya perlu resampling dan antrean PCM yang bisa dibatalkan. Hentikan antrean pemutaran saat peserta menyela. [Jembatan NAIL](../../NAIL/Resources/meet-media.cjs#L1108) · [Transport Qwen](https://www.alibabacloud.com/help/en/model-studio/realtime) · [Format dan interupsi Gemini](https://aistudio.google.com/docs/live-api/capabilities)
- Ukur p50/p90 dari akhir ucapan yang sebenarnya ke audio pertama yang terdengar di perangkat peserta lain. Catat waktu berhenti saat diinterupsi, token per sesi, memori Mac, dan kualitas bahasa Indonesia untuk nama, angka, serta campur kode. Pengukur manual Codex saat ini mulai setelah deteksi sekitar 480 ms hening. ADR 0005 mencatat acuan historis p50 ≤ 1,3 detik dan p90 ≤ 2,0 detik dari akhir ucapan ke byte audio bermakna pertama untuk perintah tanpa tool. ADR 0007 meminta pengukuran ulang. [Pengukuran Codex](../../NAIL/Resources/codex-voice.cjs#L710) · [ADR 0005](../adr/0005-latency-target-and-speculative-start.md) · [ADR 0007](../adr/0007-deepseek-for-speech-and-brain.md)
